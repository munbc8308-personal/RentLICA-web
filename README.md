# RentLICA-web

대한민국 임대사업자를 위한 법규 및 세무 정보 웹 애플리케이션

## 프로젝트 개요

RentLICA는 주택 및 상가 임대사업자가 사업을 운영하면서 알아야 할 법규, 세무, 신고 일정 등의 정보를 제공하는 웹 기반 서비스입니다.

### 타겟 사용자

- 주택임대사업자 (아파트, 빌라, 오피스텔 등)
- 상가임대사업자 (상가, 사무실 등)

## 주요 기능

### 1. 법규 정보 제공
- 주택임대차보호법
- 상가건물 임대차보호법
- 민간임대주택에 관한 특별법
- 주택임대사업자 등록 및 의무사항 안내

### 2. 세무 계산 및 안내
- 임대소득세 계산
- 종합부동산세 계산
- 부가가치세 (상가임대)
- 세금 절세 팁 및 공제 항목 안내

### 3. 일정 및 신고 알림
- 세금 신고 기한 알림 (종합소득세, 부가세 등)
- 임대사업자 의무 이행 일정
- 법규 변경 사항 알림

## 기술 스택

### Frontend
- **Framework**: Nuxt.js 3 (Vue.js 기반)
- **Language**: TypeScript
- **UI Library**: PrimeVue

### Deployment
- **Platform**: Vercel

## 개발 환경 설정

```bash
# 의존성 설치
npm install

# 환경변수 설정
cp .env.example .env
# .env 파일에 API 키 설정

# 개발 서버 실행 (http://localhost:3000)
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 미리보기
npm run preview
```

## 외부 API 연동

### 국가법령정보센터 Open API

법규 정보를 실시간으로 가져오기 위해 국가법령정보센터 Open API를 사용합니다.

1. [국가법령정보 공동활용](https://open.law.go.kr/)에서 회원가입
2. API 키 발급
3. `.env` 파일에 `LAW_API_KEY` 설정

```env
LAW_API_KEY=your_api_key_here
```

**참고:** API 키가 없어도 목업 데이터로 테스트 가능합니다.

## 설계 원칙

### Stateless / DB-less 아키텍처
- **데이터베이스 미사용**: 모든 데이터는 외부 API 또는 정적 데이터로 제공
- **서버 상태 없음**: 서버는 단순 API 프록시 역할만 수행
- **캐싱**: 필요시 클라이언트 사이드 캐싱 활용

### 인증
- **현재**: 인증 없이 서비스 제공
- **향후**: SSO(Single Sign-On) 연동 예정
- 인증 관련 코드는 별도 모듈로 분리하여 SSO 연동 시 교체 가능하도록 설계
